## Global hotkeys

These work anywhere on your system, even when Silk's panel isn't focused.

| Action | Shortcut |
|---|---|
| Push-to-talk — press once to start listening, press again to stop | `Ctrl+Space` |
| Stop Act Mode / dismiss overlay | `Escape` |
| Stop current response | `Ctrl+.` |

## Panel shortcuts

These work when the Silk panel is open and focused.

| Action | How |
|---|---|
| Open / close panel | Click the Silk icon in the menu bar or system tray |
| Open settings | Click the gear icon in the panel |
