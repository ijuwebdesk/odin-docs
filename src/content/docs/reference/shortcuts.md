## Global hotkeys

These work anywhere on your system, even when Odin's panel isn't focused.

| Action | Shortcut |
|---|---|
| Push-to-talk (hold while speaking) | `Ctrl+Space` |
| Stop Act Mode / dismiss overlay | `Escape` |
| Stop current response | `Ctrl+.` |

## Panel shortcuts

These work when the Odin panel is open and focused.

| Action | How |
|---|---|
| Open / close panel | Click the Odin icon in the menu bar or system tray |
| Open settings | Click the gear icon in the panel |
