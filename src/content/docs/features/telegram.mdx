The Telegram Bridge lets you send tasks and messages to Silk from your phone via Telegram. Silk receives them, runs them as background agent sessions, and replies in the same chat.

<Aside>
The bridge connects to the Silk instance running on your desktop. Your computer needs to be on and Silk needs to be running for the bridge to work.
</Aside>

## Setting up the Telegram Bridge

<Steps>
1. Open the Silk panel and go to **Settings → Telegram**.

2. Click **Connect**. Silk generates a time-limited pairing code and displays it on screen along with the exact command to send.

3. Open Telegram on your phone and search for **@SilkAI_bot**. Open a chat with it.

4. Send the command Silk shows — it looks like:
   ```
   /pair XXXXXX
   ```
   where `XXXXXX` is the code shown in Silk.

5. The bot confirms the pairing and Silk's settings panel updates to show **Connected**.
</Steps>

The pairing code expires after a short time. If it runs out before you send the command, click **Connect** again to generate a new one.

## Sending tasks

Once paired, any message you send to **@SilkAI_bot** in Telegram is forwarded to Silk and handled as a background agent task. Silk streams its progress back into the same Telegram chat as it works — for example, send "hey" and Silk launches an agent and replies asking what you'd like help with.

You can also send **voice messages** (Silk transcribes them) and **files / screenshots** as part of a task.

<Aside>
Sending and receiving text messages works on any paired plan. Having Silk **pull in and work with files from your computer** is included with the **Unlimited plan** — you'll need at least that tier for full file access over the bridge.
</Aside>

## Commands

In a direct chat you can just type what you want. These commands are also available; tap the **☰ menu** button in the chat to see them.

| Command | What it does |
|---|---|
| `/do <task>` | Run a task now, e.g. `/do summarise my inbox`. **Required in group chats.** |
| `/status` | What Silk is working on right now |
| `/abort` | Stop the current task |
| `/new` | Start fresh on your next message |
| `/schedule <when>, <task>` | Create a [scheduled task](/features/scheduled-tasks/), e.g. `/schedule every weekday at 9am, email me the orders` |
| `/schedules` | List your scheduled tasks |
| `/pause 1` / `/resume 1` | Pause or resume a scheduled task |
| `/unschedule 1` | Delete a scheduled task |
| `/startup on` | Start Silk at login, so schedules always fire |
| `/pair <code>` | Connect this chat to your computer |
| `/unpair` | Disconnect this chat |
| `/help` | Show what Silk can do |

## Using Silk in a group chat

You can add **@SilkAI_bot** to a Telegram group and pair the group, but there's one difference: **in a group, start every task with `/do`**.

```
/do summarise my inbox and email me the highlights
```

Plain messages in a group are never delivered to the bot. That's a Telegram privacy feature, and we keep it on deliberately, so Silk never sees your group's unrelated conversation. If Silk answers `/help` in your group but ignores everything else, this is why. All the other commands work the same as in a direct chat.

<Aside type="caution">
**A pairing connects a chat, not a person.** In a paired group, **every member can run tasks on your computer and see the results.** If you want a private remote control, pair a direct chat with the bot instead, and use `/unpair` to disconnect a group.
</Aside>

## Disconnecting

Go to **Settings → Telegram** and click **Unpair** to remove the connection, or send `/unpair` in the chat. You can re-pair at any time by clicking **Connect** again.

<Aside>
**Messaging @UseOdinAI_bot?** That was the bot's name before Odin became Silk. It has been retired and replies with a pointer to the new one. Open **@SilkAI_bot**, send `/start`, and carry on: your pairing carries over, so there is no need to pair again.
</Aside>
