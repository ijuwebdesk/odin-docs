Silk remembers stable facts about you, your work and your preferences, so you don't have to repeat yourself. What it remembers is available in every conversation and task.

<DemoClip id="1246170904" title="Silk's Memory" />

## What Silk remembers

Memory is for **facts that stay true**, not one-off details. Good things to tell Silk:

- Who you are and what you do (*"I run an online store selling candles"*).
- Where things live (*"my client files are in ~/Clients"*).
- How you like things done (*"write emails without emojis"*, *"save reports as PDF"*).
- Accounts and tools you use (*"use the Digital Products ad account"*).

Silk also saves facts like these on its own when you mention them during a task, and corrections when you tell it it got something wrong. It doesn't save today's task, a one-off question or anything private like passwords.

## Saving a memory

Just say it or type it:

> "Remember that my project is at ~/work/silk-backend."

> "From now on, always send me reports as PDFs."

## Viewing and editing memory

Open **Library → Memory** in the [app window](/features/app-window/), or **Memory** from the panel menu.

Memory is a set of **notes**, each about one subject: you, a project, a tool, a workflow. Notes that relate to each other are linked, and the view shows them as a map. Use **Search memory** to find something fast.

Click a note to open it. You can change its **Name**, its **Summary** (the one line Silk sees in its index), its **Contents** (one fact per line) and its **Links** to other notes. Pinned notes are always shown to Silk in full.

### Project memory

**Belongs to** sets which memory a note is part of: **General memory (every task)**, or a specific [project](/features/history-projects/#project-memory). Project notes are only used for tasks in that project.

## Bringing memory over from ChatGPT, Claude or Gemini

Already taught another assistant about you? Bring it across in a minute.

<Steps>
1. In Memory, click **Import**.
2. Copy the prompt Silk shows you and run it in ChatGPT, Claude or Gemini.
3. Paste the whole answer back into Silk. Nothing is saved yet.
4. Review each line and untick anything you don't want. Lines that read like instructions to Silk rather than facts about you are left out, for your safety.
5. Save. Each line becomes a note.
</Steps>

Then click **Tidy up** to group the imported notes by subject and link the ones that belong together.

## Tidy up

Over time memory can collect lots of small notes. **Tidy up** groups scattered notes by subject and gives them proper names. It's safe to run any time.

<Aside type="tip">
Silk keeps a copy of earlier versions whenever memory changes, so a tidy-up or an edit never loses anything for good.
</Aside>
